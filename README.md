# 🎓 Student Performance Prediction

A Machine Learning based web application that predicts student performance using a trained Linear Regression model. The application provides a user-friendly interface for entering student-related information and generating a predicted performance score.

## 🚀 Project Overview

Student Performance Prediction is an end-to-end Machine Learning project that includes:

- Data preprocessing
- Exploratory Data Analysis
- Feature preparation
- Machine Learning model training
- Model serialization using Pickle
- FastAPI backend
- HTML-based frontend
- Student performance prediction

The trained model is integrated with a FastAPI application to provide predictions through a web interface.
